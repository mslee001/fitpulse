{# How to copy a Peloton sign-in (Auth0 refresh) token. Shared by Get Started and the Integrations Peloton card. #}
  1. On a computer, open a private/incognito window and sign in at members.onepeloton.com.
  2. Open developer tools → Console. Chrome/Edge: ⌥⌘J on Mac, Ctrl+Shift+J on Windows. Safari: first turn on Settings → Advanced → "Show features for web developers", then Develop → Show JavaScript Console.
  3. Paste this line and press Enter. It copies your Peloton sign-in token to the clipboard. (Chrome may ask you to type allow pasting first.) 
    {% verbatim %}copy(JSON.parse(localStorage.getItem(Object.keys(localStorage).find(k => k.includes('::https://api.onepeloton.com/::')))).body.refresh_token){% endverbatim %}
  4. Paste it below and click Connect, then close the private window. Don't sign out of Peloton there first, just close it.

Why a private window: FitPulse keeps its own sign-in fresh. If it shared one with your normal browser, the two would eventually log each other out.

Treat this token like a password. FitPulse renews it automatically; you'll only need to do this again if Peloton ends the sign-in, and FitPulse will tell you when that happens.
